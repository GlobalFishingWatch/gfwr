# Function to get API dataset name for given event type

Function to get API dataset name for given event type

## Usage

``` r
gfw_endpoint(dataset_type, ...)
```

## Arguments

- dataset_type:

  Type of dataset to get API dataset name for. It can be "raster",
  "ENCOUNTER", "LOITERING", "FISHING", "PORT_VISIT", "GAP", "EEZ",
  "RFMO" or "MPA"

- ...:

  Other arguments that would depend on the dataset type.
